# Сервер MAPA

## Как подключить

1. supabase.com → **New project**. Название `mapa`, регион ближе к людям
   (для СНГ и Европы — Frankfurt), пароль базы сохранить.
2. **SQL Editor** → вставить целиком `schema.sql` → Run.
3. **Storage** → создать два хранилища:
   - `avatars` — публичное, картинки профилей;
   - `route-photos` — публичное, снимки точек маршрута.
4. **Settings → API** → скопировать **Project URL** и ключ **anon public**.
5. Положить их в `MAPA/Resources/Supabase.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>url</key><string>https://ВАШ-ПРОЕКТ.supabase.co</string>
    <key>anonKey</key><string>ВАШ-КЛЮЧ-ANON</string>
</dict>
</plist>
```

Файл в репозиторий не кладём — он в `.gitignore`.

## Какой ключ можно показывать

`anon public` — публичный по замыслу: он зашит в каждое приложение, и
всё, что через него можно, ограничено правилами доступа в базе. Именно
поэтому в `schema.sql` на каждой таблице включён Row Level Security:
ключ не даёт прав, права даёт правило.

`service_role` со страницы ниже — противоположность: он обходит все
правила. Его место на сервере, которого у нас нет. В приложение его
класть нельзя никогда.

## Входы

| Вход | Что нужно |
|---|---|
| Почта | ничего, работает сразу |
| Apple | платный аккаунт разработчика Apple, Service ID, ключ |
| Google | проект в Google Cloud, OAuth client ID |

Начинать имеет смысл с почты: она не требует ни денег, ни ожидания.

## Чего в схеме намеренно нет

**Личных сообщений.** Переписка — это не ещё одна таблица, а отдельная
обязанность: жалобы, блокировки, удаление, ответ на обращения,
возрастной рейтинг 17+ и живая модерация. Пока в приложении нет и
десяти опубликованных маршрутов, заводить переписку рано — её некому
будет читать и некому разбирать.

Жалобы и блокировки в схеме **уже есть**: без них приложение с чужим
содержимым не проходит проверку App Store (правило 1.2), и заводить их
нужно вместе с содержимым, а не после отказа.
