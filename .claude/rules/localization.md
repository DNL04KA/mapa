# Локализация в MAPA

Два языка: русский и английский. **Ключ — это русская строка.** В коде пишешь
по-русски, английский перевод лежит в `Resources/en.lproj/Localizable.strings`
под тем же ключом.

```swift
Text(String(localized: "Континенты"))        // ключ = "Континенты"
```

## Как добавлять строки

1. Пиши русский текст прямо в `String(localized:)` или `Text(...)`.
2. Запусти `python3 Tools/extract_strings.py` — он соберёт русскую таблицу
   разбором исходников и сообщит, каких ключей не хватает в английской.
3. Допиши недостающие переводы в `en.lproj/Localizable.strings` руками.

Не редактируй `ru.lproj/Localizable.strings` вручную — он генерируется.

## Числительные — только через Plural

```swift
Plural.countries(count)   // «1 страна», «2 страны», «5 стран»
```

Формы лежат в `Localizable.stringsdict`, выбирает их система. Никогда не
собирай окончание в коде через `if count == 1`: в русском пять форм поведения,
в английском две, и ветвление в коде однажды даст «5 страна». Нужна новая
категория — добавь метод в `Core/Plural.swift` и запись в оба `.stringsdict`.

## Названия географии — данные, а не подписи

- Показ пользователю: `country.displayName`, `city.displayName` — они сами
  выбирают язык через `AppLocale.isRussian`.
- `nameRU` — **ключ** каталогов достопримечательностей и фактов. Его нельзя
  переводить, подставлять в интерфейс напрямую и менять при правке данных:
  он связывает `cities.json` с `city-facts.json`.
- Английские названия уже есть в данных Natural Earth. Русские имена городов
  задаются в `Tools/city_names_ru.py`; город без перевода — ошибка сборки
  каталога, скрипт сообщает о нём.

## Контент не переводится через таблицу интерфейса

`Core/Travel/CityFacts.swift` и `CountryFacts.swift` исключены из сборщика
строк (`SKIP` в `extract_strings.py`). Это контент, его перевод — отдельная
работа. Не добавляй их строки в `Localizable.strings`.
