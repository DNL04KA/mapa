# Ревью изменений в MAPA

## Когда применять

Есть незакоммиченные правки, ветка с коммитами или названный набор файлов, и
нужно убедиться, что они не нарушают устройство проекта. Не для поиска багов
«вообще» — здесь проверяются именно договорённости MAPA.

## Порядок действий

### 1. Собери область проверки

```bash
git status --short
git diff --stat
git diff                     # или: git diff main...HEAD
```

Если правок нет — скажи об этом и остановись, не придумывай область.

### 2. Прочитай правила, которые относятся к затронутым файлам

`.claude/rules/swift-style.md`, `swiftui.md`, `concurrency.md`,
`localization.md`, `swiftdata.md`. Правило важнее твоих общих представлений о
хорошем коде: если оно противоречит привычной практике — побеждает правило,
а расхождение вынеси в отчёт отдельным пунктом.

### 3. Пройди по списку

**Версии и зависимости**
- Нет API новее iOS 16 без `if #available` и запасного пути.
- Не добавлены пакеты; `Package.swift`, `Podfile` не появились.
- `IPHONEOS_DEPLOYMENT_TARGET` не изменён.

**Проект**
- Если добавлены или удалены файлы `.swift` — перегенерирован ли проект:
  `python3 Tools/generate_project.py`. Правка `project.pbxproj` руками — ошибка.

**Дизайн-система**
- В `Features/` нет литералов цвета, размера, шрифта — только `DS.*`.
- Нет `List`, `Form`.
- Анимации идут через `motion.animation(...)` / `motion.transition(...)`,
  а не `withAnimation` напрямую.
- У каждого `.ultraThinMaterial` есть непрозрачный путь при
  `motion.reduceTransparency`.

**Локализация**
- Новый видимый текст обёрнут в `String(localized:)` / `Text(...)`.
- Количества идут через `Plural.*`, а не через `if count == 1`.
- `nameRU` не попал в интерфейс как подпись и не изменён как ключ.
- Запущен `python3 Tools/extract_strings.py`, английские переводы дописаны.

**Конкурентность**
- Вью-модели и UI под `@MainActor`; `DispatchQueue` не появился.
- Файловые операции — через `Task.detached` с приоритетом.
- Новый `@unchecked Sendable` или `nonisolated` объяснён комментарием.
- Состояние перечитывается после `await`.

**Хранение**
- Новый формат файла получил `version`; запись атомарная; старый формат
  читается, и на это есть тест.

**Доступность**
- Новые интерактивные элементы имеют `accessibilityLabel`.
- Декоративное скрыто через `accessibilityHidden(true)`.

### 4. Проверь утверждения

Не пиши «нарушает правило», не открыв файл. Для каждой находки — путь, номер
строки и правило, которое нарушено.

### 5. Запусти доступные проверки

```bash
python3 Tools/check_cities.py        # если менялись данные городов
python3 Tools/extract_strings.py     # если менялись строки
```

Тесты требуют macOS и Xcode:

```bash
xcodebuild test -project MAPA.xcodeproj -scheme MAPA \
  -destination 'platform=iOS Simulator,name=iPhone 14 Pro'
```

На Linux эта команда недоступна — так и скажи, не выдавай непройденные тесты
за пройденные.

## Как проверить результат

Отчёт годится, если по нему можно действовать: каждая находка — файл, строка,
нарушенное правило и предлагаемая правка. В конце одной строкой: что из
проверок реально запускалось, а что осталось непроверенным и почему.
