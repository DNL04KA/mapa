# Тесты MAPA

## Когда применять

Добавляется поведение в `Core/`, меняется формат хранения или данные
каталогов, падает существующий тест. Для правок только во внешнем виде
экранов тесты обычно не нужны — скажи об этом прямо, а не пиши тест ради
галочки.

## Что уже есть

27 тестов на **XCTest** в `MAPATests/`. Swift Testing не используется: он
требует Xcode 16, а проект собирается с Xcode 14.2+.

| Файл | О чём |
| --- | --- |
| `GeometryTests.swift` | проекция, обратная проекция, камера |
| `RouteCodableTests.swift` | чтение старых файлов маршрутов |
| `StatisticsTests.swift` | доли площади, прогресс по континентам |
| `CatalogTests.swift` | целостность `cities.json` и фактов |
| `SearchTests.swift` | поиск по странам и городам, оба языка |

UI-тестов нет, и цели для них в проекте тоже нет.

## Соглашения

Имена тестов — по-русски, описывают проверяемое утверждение:

```swift
func testОбратнаяПроекцияВозвращаетИсходныеКоординаты() {
```

Класс — `final class ИмяTests: XCTestCase`, импорт — `@testable import MAPA`.
Документирующий комментарий у класса объясняет, почему эта часть достойна
теста (см. `GeometryTests.swift`).

## Порядок действий

1. Определи, что именно проверяется, и найди подходящий файл. Новый файл
   заводи, только если тема не укладывается ни в один существующий.
2. Для хранилищ подставляй эфемерную реализацию (`EphemeralRouteStorage`),
   а не трогай файловую систему.
3. Меняется формат файла — добавь в `RouteCodableTests.swift` случай с
   **прежней** версией JSON и проверь, что он читается.
4. Добавил новый файл с тестами — перегенерируй проект:
   `python3 Tools/generate_project.py`.
5. Запусти:

```bash
xcodebuild test -project MAPA.xcodeproj -scheme MAPA \
  -destination 'platform=iOS Simulator,name=iPhone 14 Pro'
```

6. Проверки данных, которые работают без Xcode:

```bash
python3 Tools/check_cities.py        # столицы и координаты против границ
python3 Tools/extract_strings.py     # чего не хватает в английской таблице
```

## Как проверить результат

Тест должен падать до правки и проходить после — проверь это, а не только
второе. В отчёте укажи число тестов и что именно запускалось. Если
`xcodebuild` недоступен (Linux, нет Xcode) — скажи об этом прямо и перечисли,
что осталось непроверенным.
