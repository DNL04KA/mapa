`mapa-film.mp4` — 20 секунд, 9:16, 1080×1920, 60 к/с, H.264 и AAC 48 кГц.
Первая версия осталась нетронутой: `Promo/mapa-promo.mp4`.

## 2. Материалы

- **Логотипа нет.** Слот `AppIcon` пуст (в `Contents.json` нет ни одного
  изображения). Бренд — только слово «MAPA» системным округлым шрифтом
  (`DS.Font.brand`) и индиго `#6C5CFF` в `AccentColor`.
- **Скриншот:** один, `docs/screenshots/map.png`.
- **Фотографии:** только ссылки на Wikimedia в `country-facts.json` и
  `city-facts.json`. Хост из среды рендера закрыт, поэтому в ролике их нет.
- **Музыки и ссылок на App Store в проекте нет.** Призыва к действию в ролике
  нет: придумывать его нечестно.
- **Что пригодилось.** Геометрия и площади из `world_110m.geojson`, токены
  `DS`, пружины из `Motion.swift`, поведение карты из `WorldMapViewModel`.
  Ещё — `ExportAnimation.swift`: приложение само показывает, как страны
  проявляются по очереди, а процент досчитывается. Крючок ролика сделан на
  этом родном приёме.
- **Сторонний ролик на 36 с** (тёмная тема, макеты телефонов) не
  использован. Он собран не из этого репозитория: в нём «201 страна ·
  899 городов», а здесь 176 стран и 871 город.

## 3. Три направления

### Cinematic Earth
- **Идея:** масштаб планеты, свет, камера над миром.
- **Палитра:** бумага и тёплые тени, акценты цвета флагов.
- **Логотип:** знак всплывает над «восходом» планеты.
- **Плюсы:** зрелищно.
- **Риски:** глобуса в приложении нет — пришлось бы показывать то, чего в
  продукте нет; интерфейс появляется поздно.
- **Сценарий:** 0–5 с глобус и полёт, 5–12 с страны и процент, 12–17 с
  экраны, 17–20 с знак.

### Premium Product Film — выбрано
- **Идея:** «карта, которая заполняется». Мир в MAPA — квадрат 1×1; ролик
  ныряет в этот квадрат, и он становится экраном.
- **Палитра:** светлое полотно «Светлая» и палитра «Флаги» — обе настоящие и
  бесплатные; индиго бренда — только в знаке.
- **Логотип:** знак растекается из точки — той же пружиной, что краска по
  стране.
- **Плюсы:** продукт — главный герой, всё честное, единая логика движения.
- **Риски:** без сильного крючка может выйти спокойно. Поэтому первые 2.5 с —
  самые плотные.

### Bold Social Promo
- **Идея:** монтаж на сильную долю, гигантские цифры, страны вспышками.
- **Палитра:** белое, чёрное и один кислотный акцент.
- **Логотип:** склейка-удар.
- **Плюсы:** удержание в лентах.
- **Риски:** интерфейс перестаёт читаться, ощущение шаблона, дешевле бренд.
- **Сценарий:** 0–2 с удар и число, 2–14 с нарезка экранов по долям, 14–17 с
  статистика, 17–20 с знак.

**Почему Premium Product Film.** Крючок он берёт из родного приёма
приложения, а не из чужого жанра, и не требует ничего, чего в продукте нет.

## 5. Знак

Лист концепций — `Promo/brand/concepts.png`. Это **предложение**, а не
существующий фирменный стиль.

1. **«Растекание» — выбран.** Три круга касаются в одной точке: так краска
   расходится по стране из места касания. Анимируется той же пружиной, что
   заливка, и читается в 16 px.
2. **«Сгиб».** Сложенная гармошкой карта даёт M. Минус: сложенная карта —
   общий значок «карты».
3. **«Меркатор».** Параллели по формуле Меркатора. Минус: в мелком размере
   похоже на сетку или меню.

**Словесный знак** — монолиния с круглыми концами. Это продолжение округлого
шрифта приложения, но нарисованное своими кривыми, поэтому выглядит
одинаково везде и прорисовывается штрихом.

Файлы:
- `mapa-mark.svg` — знак;
- `mapa-lockup.svg` — знак со словом;
- `mapa-icon-1024.png` — для пустого слота `AppIcon`, в проект не
  добавлена.

## 6. Звук

`sound.py` синтезирует всю дорожку на numpy — сэмплов со стороны нет:
- пэд ре мажор со срезанным низом и пульс восьмыми в темпе 120;
- низкие удары на ключевых событиях;
- «вжухи», которые следуют за камерой и по панораме;
- колокольчики стран, тики счётчика по той же пружине, что число;
- вдох тишины перед знаком;
- звуковой логотип из трёх нот — его можно повторять в будущих роликах.

Громкость около −15 LUFS, пик −2.6 dBFS.

**Это временная дорожка.** Лицензированного трека нет; перед публикацией
музыку можно заменить, оставив акценты на тех же секундах.

## 7. Повторный рендер

Нужны Node 18+, ffmpeg, Python 3 с numpy и Playwright с Chromium:

```sh
brew install ffmpeg && python3 -m pip install numpy
npm install -g playwright && npx playwright install chromium
export NODE_PATH="$(npm root -g)"

node Promo/cinematic/render.mjs --preview                 # 30 к/с, быстро
node Promo/cinematic/render.mjs                           # финал, 60 к/с
node Promo/cinematic/render.mjs --stills 0,7,19.9 --dir /tmp/кадры
python3 Promo/cinematic/sound.py Promo/cinematic/soundtrack.wav   # только звук
node Promo/brand/export.mjs                               # знак и лист концепций
```

Живая версия со звуком — `Promo/cinematic/index.html`. Звук играет, если рядом
лежит `soundtrack.wav`.

Шрифты: на Mac страница набрана SF Pro, MP4 рендерился на Linux шрифтом Inter.

## 8. Что улучшено относительно первой версии

- **Крючок:** с первого кадра в кадре мир-квадрат с тенью и удар, к 2.5 с
  загораются 16 стран, а процент копится синхронно. Раньше было 4 секунды
  разгона.
- **Карта стала главным активом:** нырок, зажигание по площадям, перелёт,
  растекание краски — каждое движение что-то показывает.
- **Процент — отдельный момент:** наезд на число, тики и удар на 7.7.
- **Фраза «площадь, а не галочки» теперь доказана настоящей цифрой**
  приложения: Океания — 1 страна из 7, но 90 % площади.
- **Интерфейс — часть целого:** лист становится экраном, страна становится
  карточкой, полоса Океании становится шторкой к знаку.
- **Цвет:** палитра «Флаги» на светлом полотне вместо серых «Чернил»; индиго —
  только у бренда.
- **Бренд:** предложен знак, словесный знак и иконка; знак появляется своей
  анимацией и своим звуковым мотивом.
- **Звук:** раньше его не было совсем.
- **Финал:** движение останавливается на чистом фирменном экране с вопросом,
  который остаётся у зрителя.
