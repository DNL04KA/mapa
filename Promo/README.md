# Ролик MAPA

Двадцать секунд, 9:16, 1080×1920. Живёт отдельно от приложения: генератор
Xcode-проекта сканирует только `MAPA/`, и в сборку отсюда ничего не попадает.

## Идея

Главное в MAPA — честное число: какая доля суши Земли уже твоя, по площади,
а не по числу отмеченных стран. Весь ролик — одно касание. Число выходит из
белого, камера открывает карту, палец отмечает Австралию «Был», краска
растекается по стране, число прыгает с 2.5 до 7.7 %. Силуэт вырастает в
карточку страны и возвращается на карту, где всё останавливается.

Цифры не написаны руками. Шестнадцать стран (дом в Польше и поездки по Европе)
дают 2.5 %, как на скриншоте в README, а с Австралией — 7.7 %. Их считает
та же формула, что `TravelStatistics`, по площадям из `world_110m.geojson`.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | сцена: разметка, стили и таймлайн, каждый кадр — функция времени |
| `world.js` | геометрия стран в проекции Меркатора, собрана из `MAPA/Resources/world_110m.geojson` |
| `build-world.mjs` | пересобирает `world.js` |
| `render.mjs` | покадровый экспорт в MP4 через Chromium и ffmpeg |
| `mapa-promo.mp4` | готовый ролик |

## Смотреть

Открыть `index.html` в браузере, сервер не нужен. Ролик запускается сам.

- Пробел — пауза.
- `R` или кнопка «Смотреть ещё раз» — сначала.
- Ползунок — перемотка.

На Mac страница набрана системным SF Pro. В готовом MP4 вместо него Inter:
ролик рендерился на Linux, где SF Pro нет.

## Экспортировать заново

Нужны Node 18+, ffmpeg и Playwright с Chromium. Ставить их лучше глобально,
чтобы в репозитории не появился `node_modules`:

```sh
brew install ffmpeg
npm install -g playwright
npx playwright install chromium

NODE_PATH="$(npm root -g)" node Promo/render.mjs              # 30 к/с
NODE_PATH="$(npm root -g)" node Promo/render.mjs --fps 60     # плавнее, вдвое дольше
NODE_PATH="$(npm root -g)" node Promo/render.mjs --stills 0,8,19.9 --dir /tmp/кадры
```

Экспорт не записывает экран. Он по очереди просит у страницы каждый кадр
(`window.__promo.seek(t)`), поэтому ни один кадр не теряется, а результат
одинаков при каждом запуске.

## Что можно менять

- Тайминги — объект `T` в `index.html`.
- Кадры камеры — `CAM`.
- Отмеченные страны — `HOME`, `VISITED`, `TARGET`. Процент и подписи
  пересчитаются сами.
- Надписи — блоки `#caption1` и `#final`.

Цвета, отступы и пружины взяты из `DS.*` и `Motion.swift`. Если они меняются
в приложении, их стоит поменять и здесь.
